# 发布隐私检查

本轮发布要求：界面、截图、发布说明与共享代码不包含私人邮箱、手机号、账号凭据、设备标识和个人电脑目录。

已清理共享开发说明与历史清理记录中的个人目录。已扫描已跟踪文件和新增源文件，未发现私人邮箱或手机号；哈希中的数字及安全测试中的虚构 URL 不属于个人资料。界面与设计稿使用产品文案和测试内容。

签名、上传状态、设备日志和完整测试记录保留在被忽略的受控目录，不提交仓库。分享测试图前需人工核对内容，私人手记与真实定位不作公开演示素材。第三方开源许可保留依法需要的署名；这些公开署名与开发者私人联系方式分别处理。

此记录不表示上传日志、用户本机历史数据或外部平台全部完成清理，也不删除用户已有手记。已对 Android 217 安装包及 iOS 216 共享资源包检查个人目录与私密签名文件标记，未命中。iOS 模拟器截图经人工查看使用测试内容；这不替代完整二进制字符串审计。

最终 Android 包无可调试标记、权限与可信基线一致，42 份共享脚本与 iOS 资源包逐一相同；本机个人目录、签名私钥文件与测试者配置标记扫描未命中。GLM 与 DeepSeek 两种模型分别审阅脱敏变更和扫描摘要，均无具体隐私发现；实际通道均为 OpenCode Go 订阅网关，不将其描述为两个独立网关供应商，也不声称模型亲自审计了二进制或设备。
