# 日历内容下发

服务器已确认使用 124.222.88.195。目标地址为 `https://zz.zhangyue.site/weather-companion/events.json`；已恢复有效 HTTPS。客户端 `companion/content/server.json` 的 `events_url` 留空时仅使用本地内容。

客户端启动时拉取，此后每 6 小时检查。响应上限 128 KiB，不跟随重定向；失败继续使用内置或缓存日历。更新时递增整数 `revision`，完整替换活动目录，最多 128 条规则。以仓库 `companion/content/events.json` 为完整实例。

schema 2 支持如下互斥日期规则（每条选一种）：

- `month_day`：公历每年月日。
- `date`：一次性公历日期。
- `lunar_day`：农历月日，`leap_month` 指定是否闰月。
- `lunar_eve`：正确匹配除夕，兼容大小月。
- `week_day`：月份、第几个星期、星期序号，例如母亲节。
- `solar_term`：二十四节气名称。

`days` 为 1–14 天展示时长，不代表法定调休。`priority` 排序，同日活动在日历面板列出；哀思主题优先压制庆祝效果。日期按天气城市 UTC 偏移确定，无天气数据使用设备日期。

`actions` 和 `effect_id` 只能引用客户端已有白名单；不能下发脚本。内置 200 个效果编号见 `docs/calendar/特效目录.csv`。全年每日内容与农历转换表随 APK 发布，个人纪念日仅保存在手机中。

新增动作、美术资源和客户端功能通过 OTA APK 升级。发布清单和安装流程见 `docs/服务器与OTA.md`。
