## 本轮功能

- 阿晴走路连续起伏/侧摆，大肥鱼按帧解码，纹理缓存保留40帧/24MiB上限。
- 完整106套大肥鱼动作，普通日按日期/时段编排，节日/节气与个人事件复用现有日历；舞狮与月饼等可在动作图鉴预览。
- 共同时间线控制双方朝向、站位与对视；日常递热饮、接住、喝下后回应；舞狮敲鼓配合、点心递接/品尝；夜间每天一次安静陪伴。天气/哀思/低动态中断后释放双方。
- 天空/树叶局部微动，背景参数日常15Hz、互动10Hz；持续慢帧、低动态与手动关闭等回静态，不降低人物逻辑频率。Java桥统一互斥，省电检测在锁忙时读缓存，不阻塞渲染线程。
- 自动定位明确标注城市/区县与来源；定位中、失败暂用城市、手动城市、地名不可用、体验场景分别显示。地名用独立Java异步任务解析，8秒截止、取消与退出都不等待后台；Godot仅主线程10Hz短轮询，没有后台JNI/脚本回调。无新第三方定位SDK或HTTP端点。

## 资源与构建

动作资源固定上游版本与MIT许可见`godot_project/companion/fish/README.md`及LICENSE-upstream.txt；完整帧随分支保存，也可用`tools/import_fish_assets.py`复现。专用互动姿态见`godot_project/companion/art/interaction-poses-v1.png`，以原角色参考生成，两人共享一次解码的约6MiB图集。

受控打包以可信210为基线，`tools/build_interaction_test.py`只替换9份Godot4.4.1字节码、加入新姿态与发行配置，保留原有5份DEX、原生库、天气源和完整动作资源；额外加入独立地名解析辅助classes6.dex。原生辅助类用tools/build_location_helper.py编译（Android SDK jar、D8为显式参数），--test执行超时/取消/非阻塞退出的独立JVM测试，生产DEX不包含测试类。新增脚本均需编译、写入remap；不能直接使用旧源码全量构建覆盖较新的原生层。

发行配置只保留`release.example.json`空schema；实际`release.json`由受控环境最后注入，更新入口保持既有值。不得把私有配置、签名、APK、缓存、设备数据和本地交接档案提交Git。公开构建没有配置时更新服务显示暂不可用，已注入的测试包继续使用原入口。
